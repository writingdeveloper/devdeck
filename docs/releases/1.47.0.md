# DevDeck 1.47.0

## Electron 44

DevDeck now runs on Electron 44.10.0 (Chromium 152, Node.js 24). No feature changes; this release exists so the runtime update gets its own regression run.

- **macOS 13 (Ventura) or later is required** from this version on. Electron 44 dropped macOS 12. Windows and Linux requirements are unchanged (DevDeck ships x64 builds only, so the removal of 32-bit builds does not affect it).
- **Pasting a screenshot and copying an image** were moved to Electron 44's clipboard API (`clipboard.read()` / `write()` with `ClipboardItem`; `readImage()` / `writeImage()` are gone). Verified on Windows: a bitmap on the clipboard is read as `image/png` at its original size, and an image DevDeck copies can be read back.
- Reading a connection code from the clipboard (Settings → Machines) follows the same API, which is now asynchronous.
- Dependency advisories: none open (`npm audit --audit-level=high` clean).
