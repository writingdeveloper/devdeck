# DevDeck 1.45.1

## A background session in a deleted folder no longer fails to open

Opening a Claude background session could fail with `Could not open session in C:\…\3d-asset-studio: Cannot create process, error code: 267`.

- **Cause:** Claude Code still listed a background session started in July, still waiting for input, whose folder had since been deleted. DevDeck opens a background session by attaching to it from its folder. With the folder gone, Windows refused with error 267 ("the directory name is invalid").
- **Fix:** background sessions whose folder no longer exists are not listed. There is nothing to open in them.
- **Any session:** a saved or listed session whose folder was deleted or moved now says so: "its folder no longer exists: <path> (deleted or moved)". Before, Windows' bare error code was shown.
