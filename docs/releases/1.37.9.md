# DevDeck 1.37.9

- Settings are applied only after they are saved. A failed save restores the previous value and shows an error instead of looking applied. Threshold fields reject values that are not ordered, positive whole days.
- Task lists are saved with a revision. If another window or PC changed the list first, nothing is overwritten: the current list is shown and your attempted change is kept for review.
- Session titles renamed from another PC are confirmed by the host before they show as saved. Titles of disconnected or ended sessions are not changed remotely.
- Opening Projects right after a reboot no longer piles up work. When the screen gave up on a slow project list and asked again, the earlier scan kept running alongside the new one; requests now share the scan in progress. Scans slower than 20 seconds log how long each step took.

Task editing and confirmed titles across PCs need 1.37.9 on both ends. A 1.37.9 host refuses task saves from older viewers with an update message rather than accepting writes it cannot check. Notes remain last-write-wins.
