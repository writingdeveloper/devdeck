# DevDeck 1.44.0

## Claude's background sessions in the sidebar

Claude Code can run sessions in the background: `claude --bg`, or the sessions you dispatch from its agent view. DevDeck never started them, so it never showed them, and a background session waiting on you could sit unseen for days.

- **Listed:** the sidebar now has a **Claude background sessions** group. Each row shows its name, project and state:
  - **waiting for you**, marked like any session that needs you
  - running or working
  - idle
  - failed, listed for a week
- **Counted when collapsed:** the waiting ones count toward the "needs you" number on the collapsed rail.
- **Open one:** click it. It opens in a tile by attaching to it (`claude attach`), and the conversation and the session carry on exactly as they were. Once it is open in a tile it leaves the group.
- **Other PCs:** sessions running on a paired PC are listed too, from PCs on 1.44.0.
- **Not shown:** only sessions working in a folder DevDeck shows. Finished ones are not listed.

The list comes from Claude Code itself (`claude agents --json`, about 0.2 s), read every 30 seconds while DevDeck is in front of you. If Claude Code is not installed, the group simply does not appear.

## Also

- **Update all is undisturbed:** background sessions are not listed while Update all replaces Claude Code. Listing them starts `claude` briefly, which would hold the very file the update is replacing. The automated Update-all check caught this.
- **Release reliability:** the performance check in CI now exits as soon as it has printed its verdict. On the v1.42.0 release it passed, then kept the job open until it timed out, which cancelled the release until it was rerun.

## Under the hood

- **Command line:** the only value that reaches it is the short hex id Claude Code assigns. Anything else in the listing is dropped.
- **Tests:**
  - New unit tests cover parsing the listing and the sidebar grouping.
  - `qa:cockpit-tools` uses a fixture `claude` that answers `agents --json`. It checks the group, the waiting mark, and that clicking starts `claude attach <id>` in a tile.
