# DevDeck 1.37.5

This release prevents stale screens and silent save failures during everyday use.

- Switching machines immediately clears the previous machine's project actions, costs, and sidebar. Old responses stay ignored even after switching away and back.
- Tasks and Usage keep the newest request's result when responses arrive out of order. Forgetting the selected machine correctly reloads the local deck and closes its project-memory drawer.
- Failed disk writes no longer appear successful. Tasks and notes retain retryable input, checkbox state is restored on failure, and the store rolls back to its last saved state.
- Writes to projects removed from the allowed folders return an explicit error. Structurally corrupt settings recover from a valid backup.
- App shutdown waits for native terminal cleanup, including terminals already closing, and blocks new opens during shutdown. QA now rejects abnormal process exit codes.
- New Electron failure/recovery journeys cover real disk failures, retries, restart persistence, response reordering, machine removal, and Windows native terminal output.
- Releases now require all CI checks and OS builds to pass, including running the packaged Windows app, before publishing the complete artifact set.
- Updated three transitive dependencies with published fixes and added a dependency-advisory gate to CI.

See [the quality review](https://github.com/writingdeveloper/devdeck/blob/v1.37.5/docs/quality-review-1.37.5.md) for the findings, prevention strategy, and remaining test coverage limits.
