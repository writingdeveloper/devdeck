# DevDeck 1.37.7

- Projects now shows a visible, localized loading indicator naming the selected PC. After eight seconds it explains that loading is taking longer and that switching PCs remains available.
- Loading state follows the current request: obsolete responses cannot dismiss it, failures stop it, and Retry displays progress again. The notice stays in the sticky toolbar while scrolling.
- Terminal scrollback increases from the xterm default of 1,000 lines to 10,000 lines, keeping earlier output accessible during longer sessions.
- Attaching to a running terminal preserves the first output line and its initial cursor-control sequences. Only buffers actually truncated by the memory cap discard an incomplete prefix.
- Electron QA now checks delayed loading, stale responses, failed-load recovery, searching the start of 1,500 lines of native terminal output, and terminal boundaries after navigation and window resizing.

Terminal scrollback remains bounded. Remote attachment and screen recovery use recent output rather than a permanent transcript; this release does not guarantee all output survives a reconnect, refresh, or application restart. The reported title/top-edge clipping was not reproduced in the navigation and resize checks.
