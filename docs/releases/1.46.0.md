# DevDeck 1.46.0

## Close a Claude Code background session from the sidebar

The sidebar's **Background** group lists Claude Code's own background sessions (`claude --bg`, the agent view). Until now a row there offered nothing: it could be opened, but not closed — so a session that finished or failed months ago stayed in the list for good, and the only way out was the terminal.

- **The row's ⋯ menu now has Close.** DevDeck runs `claude stop <id>` (ends the session if it is still running) and then `claude rm <id>` (removes it from Claude Code's list and deletes its job record). The conversation itself is kept on disk and can still be reopened from the project's previous sessions.
- **Bulk close works for the group too**, and Ctrl/Shift-selected background rows close together with the others — asked about once.
- **Sessions on another PC** close the same way, run by that PC. If its DevDeck is older than 1.46.0 the sidebar says so instead of pretending.
- The row disappears at once; the next listing confirms it. If `claude rm` refuses, the message names the command to try by hand.

Verified on Windows with Claude Code 2.1.311: `stop` answers `stopped <id>`, `rm` answers `removed <id>`, and the session is gone from `claude agents`.
